BÀI 8: ĐỊNH DẠNG VĂN BẢN

Làm chủ các quy tắc định dạng trang web chuyên nghiệp: Sử dụng thuộc tính style, các thẻ tiêu đề (<h1>-<h6>), đoạn văn (<p>), nhấn mạnh nội dung (<strong>, <em>, <mark>) và chỉ số toán học/hóa học (<sup>, <sub>).

🚀 Bắt đầu học ngay (HĐ 1) → 📊 Xem AntV Infographic (HĐ 4)

🎯 MỤC TIÊU BÀI HỌC CẦN ĐẠT

  • 1. Cú pháp thuộc tính style: Hiểu rõ cấu trúc style="thuộc-tính: giá-trị;" để đổi màu sắc, kích thước, căn lề.
  • 2. Phân cấp văn bản: Sử dụng thành thạo thẻ tiêu đề <h1> đến <h6> và thẻ đoạn văn <p>, xuống dòng <br>.
  • 3. Nhấn mạnh ý chính: Phân biệt và ứng dụng đúng thẻ <strong> (ngữ nghĩa quan trọng) và <em> (nhấn giọng).
  • 4. Chỉ số trên/dưới: Trình bày đúng công thức toán học ($ax^2 + bx + c = 0$) và hóa học ($H_2O$) với <sup>, <sub>.
  • 5. Thực hành tự code: Tự tay gõ hoàn chỉnh cấu trúc trang web và lưu xuất file HTML độc lập.
