Dòng văn bản, Tính kế thừa, Cascading &amp; Phiếu bài tập

Kiểm soát bố cục đoạn văn (line-height, text-*) và quy tắc ưu tiên CSS (SGK tr.78–80)

1. Định dạng dòng văn bản (<code>line-height</code> &amp; <code>text-*</code>)

SGK tr.78
  • line-height: chiều cao giữa các đường cơ sở (baseline), mặc định thường 2em.
  • text-align: căn lề left, center, right, justify (đều hai bên).
  • text-decoration: none (bỏ gạch chân thẻ <a>), underline, overline, line-through. Lưu ý: Không kế thừa!
  • text-indent: khoảng thụt lề dòng đầu tiên (âm nếu muốn lồi ra ngoài).
Hình 14.4. Khái niệm đường cơ sở & chiều cao dòng (SGK tr.78)
Hình 14.5. Trình bày đoạn văn với text-align, text-decoration, text-indent (SGK tr.78)
💻 Định dạng đoạn văn bản chuyên nghiệp 
<style>
  .doan {
    line-height: 1.75;
    text-align: justify;
    text-indent: 28px;
  }
  a { text-decoration: none; color: #dc2626; font-weight: bold; }
</style>
<p class="doan">Đoạn văn này tự động thụt đầu dòng 28px, căn đều hai bên và giãn dòng 1.75 dễ đọc. Kèm <a href="#">liên kết bỏ gạch chân</a>.</p>

2. Tính kế thừa, Thứ tự Cascading, <code>*</code> &amp; <code>!important</code>

SGK tr.79–80
  • Tính kế thừa: Thuộc tính chữ (font-*, color, line-height, text-align, text-indent) truyền từ cha xuống con; còn text-decoration và border không kế thừa.
  • Cascading (xếp tầng): Khi các bộ chọn có mức ưu tiên ngang nhau, khai báo viết sau cùng thắng.
  • Bộ chọn toàn cục *: Áp dụng mọi phần tử nhưng độ ưu tiên thấp nhất.
  • Từ khóa !important: Đẩy độ ưu tiên của khai báo lên cao nhất.
Hình 14.6. Cơ chế áp dụng theo tầng Cascading (SGK tr.79)
❓ Câu hỏi củng cố (Hộp xanh SGK):
  • Nếu có 3 quy tắc: * { color: gray; }, p { color: green !important; }, p { color: red; } thì chữ trong thẻ

    màu gì?

    Chữ hiển thị màu xanh lá (green) vì khai báo đó có kèm từ khóa !important đạt độ ưu tiên cao nhất.
  • Vì sao không nên lạm dụng !important ở mọi dòng CSS?
    Vì lạm dụng !important phá vỡ thứ tự kế thừa và xếp tầng tự nhiên, khiến việc bảo trì ghi đè giao diện về sau rất khó kiểm soát.
💻 Kiểm chứng Cascading & !important 
<style>
  * { color: gray; }
  p { color: #059669 !important; }
  p { color: #dc2626; }
</style>
