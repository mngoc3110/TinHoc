Định dạng Phông chữ (<code>font-*</code>) và Màu chữ (<code>color</code>)

5 họ phông chữ chuẩn, đơn vị kích thước (px, pt, em, rem) và kiểu/độ dày chữ (SGK tr.76–77)

1. Họ phông chữ (<code>font-family</code>) &amp; Cỡ chữ (<code>font-size</code>)

SGK tr.76–77

CSS chia phông chữ thành 5 họ cơ bản: serif (có chân), sans-serif (không chân), monospace (cố định độ rộng), cursive (viết tay) và fantasy (trang trí).

Cỡ chữ font-size dùng đơn vị tuyệt đối (px = 1/96 in, pt = 1/72 in, cm, in), tương đối (em, rem, %) hoặc từ khóa (medium mặc định).

📌 Ghi nhớ SGK: Khi viết font-family, tên phông có khoảng trắng phải đặt trong nháy kép, ví dụ "Times New Roman", Georgia, serif.

Hình 14.2. Các đơn vị kích thước font-size (SGK tr.77)
💻 Thử nghiệm 5 họ phông và đơn vị cỡ chữ 
<style>
  .s1 { font-family: "Times New Roman", serif; font-size: 18px; }
  .s2 { font-family: Arial, sans-serif; font-size: 16px; }
  .s3 { font-family: "Courier New", monospace; font-size: 14pt; color: #1d4ed8; }
</style>
<p class="s1">Họ serif (có chân cổ điển)</p>
<p class="s2">Họ sans-serif (không chân hiện đại)</p>
<p class="s3">Họ monospace (hiển thị mã nguồn 14pt)</p>

2. Kiểu chữ (<code>font-style</code>) &amp; Độ đậm (<code>font-weight</code>)

SGK tr.77
  • font-style: nhận các giá trị normal (thường), italic (chữ nghiêng chuẩn), oblique. (Lưu ý kỹ: chuẩn CSS là italic, tránh gõ thừa chữ s như lỗi in cũ).
  • font-weight: nhận normal (400), bold (700) hoặc các bậc số 100–900 (từ 500 trở lên bắt đầu in đậm).
Hình 14.3. Minh họa font-style và font-weight (SGK tr.77)
❓ Câu hỏi củng cố (Hộp xanh SGK):
  • Phát biểu: 'Giá trị font-weight: 300 hiển thị chữ in đậm còn font-style: italics dùng để in nghiêng' đúng ở điểm nào và sai ở điểm nào?
    Cả 2 phần đều chưa chính xác: chữ in đậm chỉ áp dụng từ giá trị 500 trở lên (ví dụ 700 hoặc bold); và từ khóa in nghiêng chuẩn CSS là italic (không có chữ 's').
💻 Kiểm chứng font-style và font-weight 
<style>
  .nghieng { font-style: italic; color: #059669; }
  .dam700 { font-weight: 700; color: #b91c1c; }
</style>
<p class="nghieng">Dòng này in nghiêng bằng font-style: italic;</p>
<p class="dam700">Dòng này in đậm bằng font-weight: 700;</p>
