BÀI 13: KHÁI NIỆM, VAI TRÒ CỦA CSS

Mở đầu chặng thiết kế giao diện web chuyên nghiệp: Hiểu bản chất ngôn ngữ CSS (Cascading Style Sheets), cấu trúc mẫu định dạng bộ_chọn { thuộc_tính: giá_trị; }, gộp bộ chọn, chú thích /* ... */ và 3 cách thiết lập (Internal, External, Inline CSS).

🚀 Bắt đầu học ngay (HĐ 1) → 📊 Xem Infographic (HĐ 4)

🎯 MỤC TIÊU BÀI HỌC CẦN ĐẠT

  • 1. Khái niệm &amp; Cấu trúc CSS: Hiểu cấu trúc bộ_chọn { vùng_mô_tả } và cách gộp nhiều bộ chọn cách nhau bởi dấu phẩy.
  • 2. Ba cách thiết lập CSS: Phân biệt và sử dụng đúng CSS trong (<style>), CSS ngoài (<link> / @import) và CSS nội tuyến (style="...").
  • 3. Vai trò &amp; Lợi ích của CSS: Tách biệt phần trình bày khỏi nội dung HTML, đồng bộ định dạng nhiều trang chỉ bằng 1 tệp CSS.
  • 4. Cú pháp &amp; Chú thích chuẩn: Viết đúng dấu { }, dấu :, dấu ; ngăn cách từng khai báo và chú thích /* ... */.
  • 5. Thực hành Lich_su_CSS.html: Tự lập trình bài viết Lịch sử CSS áp dụng mẫu định dạng cho các thẻ h1, h2, p, ul.
💡 Năng lực số mục tiêu: 3.1.NC1b — Phân tách cấu trúc nội dung HTML khỏi định dạng trình bày bằng ngôn ngữ CSS khoa học, đồng bộ.
