Ba cách thiết lập CSS &amp; Vai trò tách biệt nội dung

Phân biệt Internal, External và Inline CSS cùng Phiếu bài tập Bài 13 (SGK tr.73–74)

1. Ba cách thiết lập CSS vào trang web

SGK tr.73
  • CSS trong (Internal CSS): Đặt cặp thẻ <style>...</style> bên trong phần <head>. Phù hợp khi thiết kế một trang HTML đơn lẻ.
  • CSS ngoài (External CSS): Viết toàn bộ CSS trong tệp riêng đuôi .css (ví dụ styles.css), rồi gắn vào <head> của nhiều trang HTML bằng <link href="styles.css" rel="stylesheet" type="text/css"> hoặc lệnh @import "styles.css"; bên trong <style>.
  • CSS nội tuyến (Inline CSS): Viết trực tiếp thuộc tính style="..." ngay trong thẻ mở HTML (ví dụ <p style="color:red;">).
📌 Ghi nhớ SGK: External CSS là phương pháp chuyên nghiệp và hiệu quả nhất cho website có nhiều trang vì đảm bảo đồng bộ và dễ bảo trì.
💻 So sánh Internal CSS và Inline CSS ngay trên trang 
<!-- Internal CSS trong head -->
<style>
  p { color: #1d4ed8; font-size: 15px; }
</style>
<p>Đoạn văn dùng Internal CSS (xanh dương).</p>
<!-- Inline CSS đè trực tiếp -->
<p style="color: #dc2626; font-weight: bold;">Đoạn văn dùng Inline CSS (đỏ đậm).</p>

2. Vai trò cốt lõi của CSS trong phát triển web

SGK tr.74

Việc sử dụng CSS mang lại 3 giá trị lớn:

  • Tách biệt rõ ràng phần cấu trúc nội dung (HTML) và phần trình bày giao diện (CSS).
  • Giảm dung lượng mã HTML lặp lại, giúp tải trang nhanh và mã nguồn dễ đọc.
  • Đồng bộ phong cách cho cả website nhiều trang: chỉ cần chỉnh sửa 1 tệp .css, hàng trăm trang web lập tức đổi giao diện thống nhất.
❓ Câu hỏi củng cố (Hộp xanh SGK):
  • Viết khai báo Internal CSS để mọi thẻ h1 có chữ màu đỏ (red) và mọi thẻ p có chữ màu xanh lá (green).
    <style> h1 { color: red; } p { color: green; } </style> đặt bên trong thẻ <head>.
  • Vì sao khi xây dựng website Câu lạc bộ gồm nhiều trang (index.html, CLB.html, the_thao.html) nên dùng External CSS thay vì copy thẻ <style> sang từng tệp?
    Dùng External CSS giúp tập trung quy tắc ở 1 tệp .css duy nhất; khi cần đổi màu chữ hay phông chữ cả 3 trang chỉ cần sửa 1 lần ở tệp CSS đó.
💻 Cú pháp thẻ <link> nhúng CSS ngoài chuẩn xác 
<!-- Ví dụ nhúng trong phần <head> của HTML -->
<div style="background:#0f172a;color:#93c5fd;padding:12px;border-radius:8px;font-family:monospace;font-size:13px;">
  &lt;head&gt;<br>
  &nbsp;&nbsp;&lt;link href="styles.css" rel="stylesheet" type="text/css"&gt;<br>
  &lt;/head&gt;
</div>
