2. Góc Lật Thẻ Ghi Nhớ (Interactive Flashcards 3D)

👆 Bấm vào từng thẻ để lật xem đáp án
Thẻ 1 • Cấu trúc CSS Một mẫu định dạng CSS gồm những bộ phận nào? Ký tự nào ngăn cách nhiều khai báo trong cùng vùng mô tả? 👆 Nhấn để lật xem lời giải
✅ Đáp án ghi nhớ:
Gồm Bộ chọn (Selector) và Vùng mô tả { ... }. Giữa các cặp thuộc_tính: giá_trị; dùng dấu chấm phẩy (;).
👆 Nhấn lần nữa để úp thẻ lại
Thẻ 2 • Chú thích CSS Cú pháp viết chú thích hợp lệ trong CSS là gì? 👆 Nhấn để lật xem lời giải
✅ Đáp án ghi nhớ:
Đặt nội dung giữa /* và */. Ví dụ: /* Định dạng tiêu đề */.
👆 Nhấn lần nữa để úp thẻ lại
Thẻ 3 • Nhúng External CSS Để liên kết tệp styles.css ở ngoài vào phần <head> của trang web bằng thẻ <link>, cần viết đầy đủ thế nào? 👆 Nhấn để lật xem lời giải
✅ Đáp án ghi nhớ:
<link href="styles.css" rel="stylesheet" type="text/css">.
👆 Nhấn lần nữa để úp thẻ lại
Thẻ 4 • Gộp bộ chọn Muốn gán chung màu đỏ cho <h1>, <h2> và <p> trong một mẫu định dạng duy nhất thì viết bộ chọn thế nào? 👆 Nhấn để lật xem lời giải
✅ Đáp án ghi nhớ:
Ngăn cách các bộ chọn bằng dấu phẩy (,): h1, h2, p { color: red; }.

3. Trả Lời Câu Hỏi Cuối Bài SGK Tin Học 12 (Luyện Tập & Vận Dụng)

LUYỆN TẬP • Câu 1: Cấu trúc mẫu CSS và 3 cách thiết lập SGK tr.75

Trình bày cấu trúc tổng quát của một mẫu định dạng CSS và phân biệt 3 cách thiết lập CSS (Internal, External, Inline).

Gợi ý chuẩn SGK:
• Cấu trúc: bộ_chọn { thuộc_tính: giá_trị; }.
• 3 cách thiết lập: (1) Internal CSS đặt trong thẻ <style> ở <head>; (2) External CSS tách thành tệp .css ngoài rồi nhúng bằng <link> hoặc @import; (3) Inline CSS đặt thuộc tính style="..." trực tiếp trên thẻ HTML.
LUYỆN TẬP • Câu 2: Phát hiện & sửa lỗi cú pháp CSS SGK tr.75

Khi viết CSS, nếu học sinh viết: h1 { color = red, font-size 24px } thì sai ở những chỗ nào? Sửa lại cho đúng.

Sai 3 điểm: thiếu dấu hai chấm : ở font-size, dùng dấu = thay cho : ở color, và dùng dấu phẩy , thay cho chấm phẩy ;.
Sửa lại: h1 { color: red; font-size: 24px; }.
VẬN DỤNG • Tách định dạng thành tệp styles.css cho Website CLB SGK tr.75

Viết nội dung tệp styles.css định dạng tiêu đề h1, h2 màu xanh dương đậm, đoạn văn p cỡ chữ 16px và nêu cách gắn vào cả 2 tệp index.html và CLB.html.

/* Trong tệp styles.css */
h1, h2 { color: #1e3a8a; }
p { font-size: 16px; }

<!-- Đặt trong <head> của cả index.html và CLB.html -->
<link href="styles.css" rel="stylesheet" type="text/css">
